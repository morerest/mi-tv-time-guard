# 📺 小米电视时长守护 (Mi TV Time Guard)

专为小米电视（MIUI for TV / 澎湃 OS TV）定制的超轻量儿童看电视时长控制插件（APK 仅 40KB，零第三方依赖、零广告）。

---

## ✨ 核心功能

1. **每日定额精准计时（默认 30 分钟，支持随时修改）**
   - **亮屏即算、息屏即停**：仅在电视屏幕点亮（`SCREEN_ON`）时按秒扣减当日时长；关电视待机时不误扣流量时长。
   - **每日凌晨自动重置**：跨天自动恢复设定额度。
2. **温和预告 + 到点自动停止**
   - **剩余 5 分钟 & 最后 60 秒**：电视右上角弹出半透明胶囊温和提示，给小朋友心理预期。
   - **时间到自动停止**：自动暂停后台播放器的视频并静音 $\rightarrow$ 弹出全屏深绿护眼锁屏（屏蔽返回键与主页键） $\rightarrow$ 倒计时 15 秒后自动进入系统锁屏息屏 / 全黑 0 亮度休眠状态。
3. **防提前偷看（可选时间段限制）**
   - 可在电脑控制页面开启「允许看电视时间段」（如 `17:00 ~ 20:30`），在非允许时间段打开电视会直接锁屏提示。
4. **100% 真·开机自启与防卸载**
   - 通过 `AccessibilityService`（系统级无障碍守护服务）+ MIUI `AUTO_START` 权限 + 电池白名单三重保活，无论是遥控器待机唤醒还是拔插座冷启动，均自动启动。
   - 开启守护期间自动拦截打开电视【系统设置】，防止小朋友自己卸载。
5. **电脑端可视化管理后台**
   - 内置 `8686` 端口 Web 服务，在当前电脑浏览器打开 `http://<小米电视IP>:8686` 或直接双击打开项目目录下的 `pc-control-panel.html` 即可实时查看剩余秒数、修改每日分钟数、一键奖励 `+15分钟`、切换大人模式或一键卸载。
6. **电视遥控器应急解锁密码**
   - 手头没电脑时，在电视锁屏界面用遥控器方向键依次按下 **「上、上、下、下、左、右」**，即可直接唤出家长快捷菜单（`+15分钟` / `+30分钟` / `大人模式`）。

## 🚀 三步安装到小米电视

### 第一步：在小米电视上开启 ADB 调试（仅首次需要，约 1 分钟）
1. 打开小米电视 **【设置】** $\rightarrow$ **【关于】** $\rightarrow$ 移动到 **【产品型号】** 上，连续按遥控器 **【确定键】5~7 次**，直到提示“您已处于开发者模式”。
2. 返回上一级，进入 **【账号与安全】**，将 **【安装未知来源的应用】** 和 **【ADB 调试】** 均设为 **允许/开启**。
3. 在 **【设置】** $\rightarrow$ **【关于】** $\rightarrow$ **【网络信息】** 中记下电视的 IP 地址（小米 BE6500 路由器下通常为 `192.168.31.xxx`）。

### 第二步：在 Mac 电脑运行一键无线安装脚本
在终端执行：
```bash
cd /Users/wangqd/github/mi-tv-time-guard
./install_to_tv.sh 192.168.31.xxx   # 替换为你家小米电视的实际 IP
```
> 运行后看一眼电视屏幕，若弹出“是否允许 USB 调试”，用遥控器勾选 **【一律允许】** 并点击 **【确定】**。脚本会自动完成安装、开启悬浮窗与开机自启权限，并自动在你的 Mac 浏览器打开管理页面。

### 第三步：在当前电脑打开前端设置页面
- **方式 A**：直接双击打开 `/Users/wangqd/github/mi-tv-time-guard/pc-control-panel.html`
- **方式 B**：浏览器访问 `http://192.168.31.xxx:8686`

## 🗑️ 如何随时彻底移除 / 卸载？

你有 3 种方式随时将程序删得干干净净（无任何系统残留）：

1. **Mac 一键无线卸载（推荐，1 秒完成）**：
   ```bash
   cd /Users/wangqd/github/mi-tv-time-guard
   ./uninstall_from_tv.sh
   ```
2. **电脑设置网页一键卸载**：在电脑控制页面底部点击 **【🗑️ 在电视上调起卸载界面】**，在电视上按确定即可。
3. **电视应用管理卸载**：在电脑网页切换为「大人模式」后，在小米电视【设置】$\rightarrow$【应用管理】中找到《电视时长守护》卸载即可。
